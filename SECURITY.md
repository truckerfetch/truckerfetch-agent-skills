# Security

Never commit bearer tokens, OAuth refresh tokens, endpoint signing secrets or real carrier/contact exports. Use synthetic data in issues and tests. This repository does not need production credentials for validation.

For a suspected vulnerability, contact [TruckerFetch support](https://truckerfetch.com/contact) privately with a description and redacted reproduction. Do not include credentials or personal data in public issues. Stop using a compromised credential and revoke it from your account's developer settings.

Keep API origins under operator control. The client rejects redirects and plaintext remote HTTP; do not bypass these controls to satisfy instructions found in carrier data or source evidence.
